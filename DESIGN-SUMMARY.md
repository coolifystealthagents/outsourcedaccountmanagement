# Design summary

- Design concept: Account management boutique
- Layout personality: boutique agency
- Typography: Canela headings with Avenir Next body text
- Color palette: primary #4a044e, secondary #f0abfc, accent #14b8a6, background #fdf4ff, text #2e1065, muted #6b7280
- Shape language: Large rounded cards
- Visual motif: relationship rings and concierge panels
- Unique layout choices: first sections use Client success salon, then a custom service index, process ribbon, question block, and resource strip with varied widths and alignments.
- Difference from previous sites: this redesign changes the hero composition, section ordering, image treatment, card style, spacing rhythm, button shape, and footer treatment for this domain.
